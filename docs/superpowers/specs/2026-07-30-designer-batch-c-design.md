## C1 External panel（v0.3 便宜半）

- 交互：从 Finder 拖 png/jpg/jpeg/tif/tiff 文件到某 panel 上 → 该 panel 变 external：画布内显示等比缩放的缩略底图（保持 panel 卡片样式，图像居中 letterbox），侧栏出现 asset 区块：文件名、原始像素、**有效 DPI**（`asset_px / (panel_mm / 25.4)` 取两轴较小者）与红黄绿灯（≥ min_effective_dpi 绿；≥ 0.67× 黄；更低红）。再次拖入替换；侧栏 "Remove asset" 还原 generated 占位。
- 数据模型：PanelNode 新增可选 `asset: str | None`、`asset_px: tuple[int, int] | None`（sidecar 序列化）。asset 路径：spec 文件已保存时存相对路径（相对 spec 所在目录），未保存文档暂存绝对路径、保存时若可相对化则转换。
- spec 导出：带 asset 的 panel 输出 `"type": "external"` + `asset` + `asset_px`，不输出 `source`；其余 panel 维持现状（type 省略 = 仅版式占位，兼容 v0.3 语义）。constraints 新增 `min_effective_dpi: 300`（figspec.spec.Constraints 加字段，默认 300；旧文件无此键 → 默认，前向兼容）。打开时恢复 external 状态（asset 文件缺失 → panel 显示"missing asset"警示态，不崩）。
- 像素读取用 QImageReader（只读尺寸，不载全图内存）。

## C2 Archetype 模板库

- 新共享模块 `figspec/templates.py`（**放 figspec 包**，未来 MCP `new_spec(template=…)` 直接复用）：`TEMPLATES: dict[str, Template]`，Template = {key, title, description, build() -> Node}。四个原型（竞调自真实 Nature 版式提炼）：
  1. `quantitative_grid`：2 行 × 3 列等分网格
  2. `hero_left`：左整高大 panel（60%）+ 右列上下两 panel
  3. `image_plate`：3 行 × 4 列网格（图像板，建议配小 gutter，模板只建树不改 gutter）
  4. `asymmetric`：上整行 hero + 下行三等分
- Designer：File > New from Template… 对话框：左列表右预览（预览 = flatten 后 QPainter 画线框 + 标号，120×90 缩略）；选择后以当前 preset/height 建新文档（沿用未保存确认流程）。
- 树构建用 figspec.layout（split_panel_n 等分能力来自批次 A——**C 依赖 A 先合并**）。

## C3 Copy matplotlib snippet

- File 菜单 + 侧栏按钮 "Copy matplotlib Snippet"：生成整图代码块进剪贴板：
  - 头部注释：`# Generated by FigSpec Designer from <name> — regenerate after layout changes`（明示保质期；M1 渲染落地后此功能自然退役）
  - rcParams 块：由当前 constraints 派生（font.size=min_font_pt 起步、axes.labelsize、xtick/ytick.labelsize、axes.linewidth=min_linewidth_pt、svg.fonttype none、pdf.fonttype 42——沿用竞调确认的最佳实践参数集）
  - 每 panel：`fig_a, ax_a = plt.subplots(figsize=(3.524, 1.969), dpi=600)  # panel a: 89.5 × 50.0 mm — <content_hint>` + `fig_a.savefig("panel_a.pdf")`
- 纯字符串生成，实现放 `figspec/snippet.py`（同样留给 MCP 复用），Designer 只是调用方。

## C4 版式线框导出

- File > Export Layout Preview…（PNG）：专用 QPainter 渲染（不用 canvas.grab，避免选中态/悬停按钮入图）：白底页面 + panel 灰框 + 标号 + 每 panel 尺寸 mm 标注 + 底部整图信息行（preset、W×H mm、DPI、gutter），2× 分辨率输出。实现为 `ui/preview_export.py` 纯函数 `render_layout_png(doc, path, scale=2)`。
